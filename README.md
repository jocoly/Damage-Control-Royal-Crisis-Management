# Damage Control: Royal Crisis Management

Damage Control is a small desktop prototype about managing royal influence through real-world keyboard and mouse activity.

## Install

Windows users can download the latest installer from the [Releases page](https://github.com/jocoly/Damage-Control-Royal-Crisis-Management/releases/latest) and run it.

The installer includes Damage Control and handles the Microsoft Edge WebView2 runtime if it is missing. A machine that does not already have WebView2 may need internet access during installation so the runtime bootstrapper can download.
